### `medxpert-reg-hub` · 医械注册工程师·全球通关枢纽

- **一句话定位**：医疗器械注册工程师的随身资料库——免费、免 API Key、默认本地运行、数据不出本机、不强制上传，即装即用。
- **核心能力**：覆盖中国 **NMPA** / 美国 **FDA 510(k)** / 欧盟 **EU MDR·CE** / 日本 PMDA 及东南亚·拉美全球注册路径与分类；内置 **UDI**、**STED** 技术文件、生物相容性（ISO 10993）、GMP 质量体系、上市后监管、标签与 IFU、供应商合规等 20 个专题枢纽，按「全生命周期 7 阶段」编排，官方直达链接一站备齐（已逐条核验可达）。
- **适用场景**：产品立项分类、注册路径判定、UDI 发码、技术文件/STED 撰写、发补应对、多市场横向对比。

- **适用场景**：免临床判定、同品种比对论证、CER 撰写、文献检索方案、境外临床数据评估。

- **关键词标签**：`医疗器械合规` · `合规评分` · `ISO 13485` · `ISO 14971` · `STED` · `标签IFU` · `PMS` · `差距分析`

- **核心能力**：中/美/欧/日四市场上市后义务对照（不良事件报告、PSUR、FSCA/召回、PMCF）+ 各市场报告时限与流程清单 + PMS 计划/PSUR 撰写框架；依据对齐 FDA MDR、MDCG 2022-21、中国 2018 年 1 号令。

<a id="skill-risk-management"></a>
### `medical-device-risk-management` · 医械风险管理专家

- **一句话定位**：医疗器械风险管理（**ISO 14971:2019** / GB/T 42062-2022）专题技能，每份注册案卷的必备文件。
- **核心能力**：六步风险流程实操（风险分析→评价→控制→综合剩余风险→报告→生产后反馈）+ 危害识别清单 + 风险矩阵与可接受准则 + 风险管理报告框架；一套文件映射 GB/T 42062 / EN ISO 14971 / JIS T 0304 / FDA 认可共识标准。
- **适用场景**：风险管理报告撰写、危害识别、风险矩阵制定、设计控制衔接。
- **关键词标签**：`风险管理` · `ISO 14971` · `GB/T 42062` · `风险管理报告` · `医疗器械注册` · `获益风险`

<a id="skill-samd"></a>

- **核心能力**：SaMD 判定与 IMDRF N12 风险分类（I–IV 类）+ IEC 62304 软件生命周期（A/B/C 级）+ FDA 软件三级关注（Major/Moderate/Minor）+ MDR 软件分类规则 11 + 网络安全（MDCG 2019-16、SBOM）评估清单。
- **适用场景**：独立软件/含软件器械分类、软件文档搭建、网络安全评估、AI 医疗器械注册。
- **关键词标签**：`SaMD` · `软件医疗器械` · `IMDRF` · `IEC 62304` · `MDR` · `网络安全` · `FDA` · `AI医疗`
